# MY.STORY — มารู้จักโรซีนกัน

เว็บแนะนำตัวของโรซีน รวมเรื่องราวส่วนตัว กิจกรรมที่ชอบ คอสเพลย์ ของสะสมอนิเมะ และคลิปโปรดไว้ในหน้าเดียว ใช้โทนม่วงลาเวนเดอร์–ชมพูบนพื้นขาวนวล พร้อมกรอบรูปสไตล์โพลารอยด์และการ์ดแนวอัลบั้มภาพ

## สิ่งที่อยู่ในเว็บ

- หน้าเปิดพร้อมรูปและข้อความทักทาย
- ส่วนแนะนำตัว (`#about`)
- การ์ดเรื่องราว 3 ใบ: แนะนำตัว กิจกรรมที่ชอบ และกิจกรรมเสริม (`#moments`)
- วิดีโอ YouTube พร้อมเหตุผลที่ชอบ (`#favorite`)
- เมนูสำหรับมือถือและปุ่มกลับขึ้นด้านบน

## เทคโนโลยี

ใช้ HTML5 และ CSS ล้วน ไม่มี JavaScript, framework หรือขั้นตอน build ใช้ CSS Grid, Flexbox และ media queries เพื่อปรับหน้าตาตามขนาดหน้าจอ มีแถบข้อความเลื่อนด้วย CSS และรองรับการตั้งค่าลดการเคลื่อนไหว (`prefers-reduced-motion`)

ฟอนต์ภาษาไทยใช้ **Prompt** และภาษาอังกฤษใช้ **DM Sans** จาก Google Fonts

## โครงสร้างไฟล์

```text
web-introduce/
├── index.html          # เนื้อหาและโครงสร้างหน้าเว็บ
├── style.css           # สี ฟอนต์ เลย์เอาต์ และการแสดงผลบนมือถือ
├── README.md
└── images/
    ├── banner.jpg      # รูปแนะนำตัวในหน้าเปิด
    ├── profile.jpg     # รูปการ์ดแนะนำตัว
    ├── activity.jpg    # รูปการ์ดกิจกรรมที่ชอบ
    ├── hobby.jpg       # รูปการ์ดกิจกรรมเสริม
    └── banner.jpeg     # ภาพเดิมที่เก็บไว้ ปัจจุบันไม่ได้ใช้ในหน้าเว็บ
```

## วิธีเปิดเว็บ

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

ถ้าต้องการเปิดผ่าน local server และมี Python 3 ติดตั้งอยู่ ให้รันคำสั่งนี้จากโฟลเดอร์โปรเจ็กต์:

```bash
python3 -m http.server 8000
```

จากนั้นเปิด <http://localhost:8000> และกด `Ctrl+C` ในเทอร์มินัลเมื่อต้องการหยุดเซิร์ฟเวอร์

การโหลดฟอนต์ Google Fonts และการรับชมวิดีโอ YouTube ต้องใช้อินเทอร์เน็ต หากฟอนต์โหลดไม่ได้ เบราว์เซอร์จะใช้ฟอนต์สำรอง

## วิธีปรับเนื้อหา

### ข้อความ

แก้ข้อความใน `index.html` โดยค้นหาประโยคที่ต้องการเปลี่ยน หรือค้นหา ID ของส่วนต่าง ๆ เช่น `hero-title`, `about`, `moments` และ `favorite` ส่วนชื่อแท็บเบราว์เซอร์แก้ได้ที่ `<title>`

### รูปภาพ

นำรูปใหม่มาแทนที่ไฟล์เดิมใน `images/` โดยใช้ชื่อและนามสกุลเดิม หรือเปลี่ยนค่า `src` ของ `<img>` ใน `index.html` ให้ตรงกับไฟล์ใหม่ พร้อมปรับ `alt` ให้อธิบายรูปนั้น

หากรูปถูกครอปไม่ตรงตำแหน่งที่ต้องการ ให้ปรับ `object-position` ใน `style.css` ที่ `.hero-portrait img` หรือ `.story-photo img` หากเปลี่ยนรูปหน้าเปิดเป็นรูปที่มีสัดส่วนต่างจากเดิม ให้ปรับ `width` และ `height` ในแท็ก `<img>` ให้ตรงกับขนาดรูปใหม่ด้วย

### สีและเลย์เอาต์

สีหลักอยู่ใน `:root` ด้านบนของ `style.css`:

| ตัวแปร | ใช้สำหรับ |
| --- | --- |
| `--ink` / `--ink-dark` | หัวข้อและสีเข้มหลัก |
| `--text` / `--muted` | ข้อความทั่วไปและข้อความรอง |
| `--cream` / `--paper` | พื้นหลังและพื้นสีขาว |
| `--purple` | สีม่วงเน้น |
| `--pink` | สีชมพูเน้น |
| `--lavender` | สีม่วงอ่อน |
| `--border` | เส้นขอบ |
| `--max-width` | ความกว้างสูงสุดของเนื้อหาหลัก |

บางส่วนกำหนดสีโดยตรงในกฎ CSS เช่น `.hero-banner`, `.ticker` และ `.favorite-section` หากเปลี่ยนธีมทั้งหน้า ให้ปรับส่วนเหล่านี้ร่วมด้วย

เลย์เอาต์มีจุดปรับขนาดที่ 1100, 860 และ 620 พิกเซล โดยเปลี่ยนเป็นเมนูมือถือเมื่อความกว้างไม่เกิน 860 พิกเซล และเรียงการ์ดเป็นคอลัมน์เดียวเมื่อไม่เกิน 620 พิกเซล

### วิดีโอ YouTube

ใน `index.html` ให้เปลี่ยน Video ID ปัจจุบัน `RFyEcpjnfb8` ให้ตรงกันทั้งสองจุด:

```text
https://www.youtube-nocookie.com/embed/VIDEO_ID?rel=0
https://www.youtube.com/watch?v=VIDEO_ID
```

จุดแรกเป็น `src` ของ `<iframe>` และจุดที่สองเป็น `href` ของปุ่มรับชมบน YouTube พร้อมแก้ `title` ของ iframe ชื่อคลิป ชื่อช่อง และคำบรรยายให้ตรงกับวิดีโอใหม่

## การนำขึ้นโฮสต์

นำ `index.html`, `style.css` และโฟลเดอร์ `images/` ไปไว้บนโฮสต์ที่รองรับเว็บไซต์แบบ static โดยรักษาตำแหน่งและชื่อไฟล์ให้เหมือนเดิม ไม่ต้องมีเซิร์ฟเวอร์ฝั่งแอปพลิเคชันหรือฐานข้อมูล
